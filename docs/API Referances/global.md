# CallSight AI - API References

Base path: `/api/v1/`

## Authentication

Most endpoints require a JWT access token using:

`Authorization: Bearer <access_token>`

Anonymous endpoints:

- `POST /auth/register/`
- `POST /auth/login/`
- `POST /auth/refresh/`

## DRF error format

Most validation/permission errors generated by DRF exceptions are wrapped by `core.exceptions.custom_exception_handler`:

{
  "success": false,
  "error": {
    "code": "bad_request|unauthorized|forbidden|not_found|conflict|too_many_requests|internal_server_error",
    "message": "Human readable message",
    "detail": { "field": ["error message"]}
  }
}

Note: a few endpoints return `{"detail": "..."}` directly (using `Response(..., status=...)`) instead of raising an exception.
